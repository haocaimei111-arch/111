# 社区视频交互原型

这是用于产品和开发评审的完整前端原型。代码不依赖在线接口或外部 CDN，可以直接运行和二次修改；正式上线前仍需按生产项目的框架、接口、鉴权和测试规范重构。

## 运行方式

最简单的方式：直接用浏览器打开 `index.html`。

本地服务方式（推荐）：

```powershell
./start.ps1
```

然后访问 `http://localhost:4173/?variant=A`。

macOS 或 Linux 可在当前目录执行：

```bash
python3 -m http.server 4173
```

## 视觉方案

- `?variant=A`：现有社区双列瀑布流，建议首期采用。
- `?variant=B`：单列大封面，强化视频内容识别。
- `?variant=C`：主题画册，突出角色和话题探索。

页面底部切换器或键盘左右方向键可以切换方案。场景选择器可验证正常、弱网、禁止下载和审核驳回状态。

## 目录结构

```text
index.html                 页面入口
styles.css                 完整视觉与响应式样式
app.js                     页面数据、状态与交互逻辑
assets/                    本地图片及 Lucide 图标库
docs/                      产品需求补充文档
prototype-preview.jpg      主要页面预览
start.ps1                  Windows 本地服务启动脚本
```

## 已实现流程

- 首页最新、推荐、关注切换，以及三套首页布局。
- 视频详情播放/暂停、进度、上下切换、弱网提示。
- 点赞、收藏、关注、评论抽屉、分享、禁止下载。
- 视频发布设置、草稿、上传/转码/审核状态及驳回态。
- 个人主页、浏览人数、置顶及作品管理菜单。

## 接入生产代码前需替换

- 将 `posts` 静态数据替换为作品、推荐和个人主页接口。
- 将内存状态替换为项目现有状态管理及路由。
- 接入真实播放器、分片上传、转码状态查询、审核和下载鉴权。
- 按 `docs/社区新增-视频_查漏补缺.md` 接入状态机、指标口径和埋点。
